Q&A

자주 묻는 질문 (FAQ)

자소서 메이트 이용에 관한 궁금증을 해결해 드립니다.

AI가 생성한 문단은 훌륭한 '초안' 역할을 합니다. 본인의 지원 기업명, 구체적인 프로젝트 이름, 솔직한 느낌을 덧붙여 나만의 어조로 윤문하신 후 제출하시는 것을 강력히 권장합니다.

Google의 고효율 고성능 모델인 Gemini 1.5 Flash를 사용합니다. 빠른 생성 속도와 자연스러운 한국어 문장 구사력을 갖추고 있습니다.

자소서 메이트는 서버리스 방식으로 동작하며, 사용자가 입력한 내용은 문장 생성을 위한 1회성 API 요청으로만 처리되고 별도 데이터베이스에 영구 저장되지 않습니다.

네트워크 지연이나 일시적인 API 트래픽 과다로 오류가 발생할 수 있습니다. 1~2초 후 '문장 생성하기' 버튼을 다시 눌러주시거나, 입력 내용이 빠진 곳이 없는지 확인해 주세요.
